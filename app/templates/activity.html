How the window works

The poller sits on the clock — :00, :15, :30, :45. Start the server at 6:03 and the first extract runs at 6:15, covering mail from 6:00 to 6:15. Start at 5:48 and the first run is 6:00, covering 5:45–6:00. Mail from before that slot is not backfilled.
